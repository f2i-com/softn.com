HTML in SoftN

About

Three pages of one site. Opened as files of your own site (the address bar shows /index.html), each page starts SoftN itself with <script src="softn/softn.js">, and a link goes to the next page as in any site.

Opened as a bundle in the standalone runtime (/app/), the same files are one app: a link to another page shows it in place, and the browser's Back button returns.
