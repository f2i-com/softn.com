Overview

This page is plain HTML with SoftN components mixed in. The items on the left are <NavItem> components:

  • Overview, Counter and Notes use page="…": they set currentPage, and the item for the page showing is highlighted.
  • To-do list and About use navigate="tasks.html": another page of the site, as a link.

The to-do list is written as a browser would run it: document.getElementById, addEventListener, createElement, inside SoftN's sandbox.
